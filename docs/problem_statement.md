# Sales Analysis Project - Problem Statement

## 1. 프로젝트 목적

최근 12개월 순매출 변화를
구매고객 수, 구매 빈도와 객단가로 분해하고,
상품·채널·고객군별 성과를 비교하여
다음 분기 우선 관리 대상을 제안한다.

## 2. 의사결정자

온라인 쇼핑몰 운영 및 CRM 담당자

## 3. 의사결정

분석 결과를 이용하여 다음 분기의:

- 우선 관리 고객군
- 강화 또는 회복이 필요한 상품군
- 점검이 필요한 판매 채널

을 결정한다.

## 4. 분석 질문

1. 최근 12개월 월별 순매출은 어떤 추세인가?
2. 매출 변화는 구매고객 수, 구매 빈도와 객단가 중 어디에서 발생했는가?
3. 상품 카테고리별 순매출과 성장률은 어떻게 다른가?
4. 채널별 순매출과 고객 기여는 어떻게 다른가?
5. 신규 고객과 기존 고객의 매출 기여는 어떻게 다른가?
6. 재구매 고객은 전체 매출에 얼마나 기여하는가?
7. 다음 분기에 우선 유지 또는 회복해야 할 대상은 무엇인가?

## 5. 핵심 KPI

- Net Sales
- Order Count
- Buyer Count
- Average Order Value
- Orders per Buyer
- Repeat Purchase Rate
- Monthly Sales Growth

## 6. 분석 단위

기본 분석 단위:

- 고객: 고객 1명당 1행
- 주문: 주문 1건당 1행
- 주문상품: 주문-상품 1건당 1행
- 상품: 상품 1개당 1행

최종 KPI 분석에서는 질문에 따라
월, 고객, 카테고리와 채널 단위로 집계한다.

## 7. 데이터 요구사항

필수 데이터:

- customers
- orders
- order_items
- products

필수 정보:

- customer_id
- order_id
- order_date
- order_status
- product_id
- category
- quantity
- unit_price
- discount

환불 데이터가 존재할 경우
환불 금액 또는 반품 수량도 반영한다.

## 8. 순매출 정의

기본 정의:

Net Sales
=
Gross Sales
- Discount
- Refund

실제 데이터 구조에 따라
최종 산식을 다시 확정한다.

## 9. 분석 한계

현재 단계에서는 사용할 공개 데이터를 아직 확정하지 않았다.

따라서 실제 분석 기간,
주문 상태 포함 기준,
환불 처리 방식과 데이터 품질 규칙은
데이터 소스 확정 후 최종 결정한다.

프로젝트 결과는 데이터가 지원하는 범위 안에서만 해석하며,
관찰 데이터의 관계를 인과관계로 표현하지 않는다.
