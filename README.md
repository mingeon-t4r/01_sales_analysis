# Sales Analysis

온라인 쇼핑몰의 최근 12개월 매출 변화를
구매고객 수, 구매 빈도와 객단가로 분해하고,
상품·채널·고객군별 성과를 분석하는 포트폴리오 프로젝트입니다.

## Project Goal

단순히 매출 증감만 확인하는 것이 아니라
매출 변화가 어떤 구성 요소에서 발생했는지 분석하고
다음 분기의 우선 관리 대상을 제안합니다.

## Core Questions

1. 월별 순매출은 어떻게 변화했는가?
2. 변화는 구매고객 수, 구매 빈도, 객단가 중 어디에서 발생했는가?
3. 어떤 상품군과 고객 지역이 성과 변화를 주도했는가?
4. 신규/기존 및 재구매 고객의 매출 기여는 어떻게 다른가?
5. 다음 분기 어떤 대상을 우선 관리해야 하는가?

## Core Metrics

- Net Sales
- Orders
- Buyers
- Average Order Value
- Orders per Buyer
- Repeat Purchase Rate
- Monthly Growth

## Data Source

Brazilian E-Commerce Public Dataset by Olist

- Real commercial ecommerce data
- Anonymized
- Period: 2016-2018
- Source: Kaggle / Olist

Raw data is not included in this repository.
